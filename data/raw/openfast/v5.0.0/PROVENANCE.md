# OpenFAST v5.0.0 reference data

The `5MW_OC3Mnpl_DLL_WTurb_WavesIrr` primary input and binary reference output
were downloaded from the official
[`OpenFAST/r-test`](https://github.com/OpenFAST/r-test) release tag `v5.0.0`.
The case is OpenFAST certification test 19: the NREL 5 MW baseline turbine with
the fixed-bottom OC3 monopile support structure, irregular waves, and wind.

These two files are pinned inputs for Stage 17. The `.outb` file is an official
OpenFAST regression baseline, not a simulation generated by this repository.
The incomplete input deck is retained only for configuration provenance and
cannot be executed without the remaining official `r-test` dependencies.
