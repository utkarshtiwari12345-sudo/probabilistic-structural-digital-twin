# Changelog

All notable changes to this project are documented in this file. The project
uses semantic versioning for software releases.

## [0.1.0] - 2026-08-24

### Added

- a verified six-degree-of-freedom structural-dynamics foundation;
- batch and sequential Bayesian stiffness-deterioration inference;
- identifiability, robustness, discrepancy, calibration, and sensor-layout
  studies with predeclared gates;
- a checksum-pinned OpenFAST v5.0.0 OC3-monopile bridge and controlled damage
  experiments;
- independent turbulent-wind and irregular-wave confirmation environments;
- distributed-moment feature selection and external confirmation;
- 203 automated tests, continuous integration, release manifests, and
  research-grade provenance documentation.

### Scientific boundary

The matched-excitation oracle confirms recoverable damage information in the
distributed moment channels. The current commissioning-reference
normalisation is not supported as an operational detector because independent
confirmation retains false alarms and incomplete detection/localisation. These
negative results are part of the release, not hidden exceptions.
